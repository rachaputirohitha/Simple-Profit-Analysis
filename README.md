# Task 16 – Simple Profit Analysis

## Objective
Analyze the SampleSuperstore dataset to compare total and average profit across different product categories.

## Dataset
SampleSuperstore

## Tools Used
- Microsoft Excel
- GitHub

## Analysis Performed

### 1. Total Profit by Category
Used the SUMIF formula to calculate total profit for each category.

Formula:
=SUMIF($H:$H,O2,$M:$M)

### 2. Average Profit by Category
Used the AVERAGEIF formula to calculate average profit for each category.

Formula:
=AVERAGEIF($H:$H,O2,$M:$M)

## Profit Summary

| Category | Total Profit | Average Profit |
|---|---:|---:|
| Furniture | 18,451.27 | 8.70 |
| Office Supplies | 122,490.80 | 20.33 |
| Technology | 145,454.95 | 78.75 |

## Visualization
Created a column chart titled:

**Total Profit by Product Category**

Axis titles:
- X-axis: Product Category
- Y-axis: Total Profit

## Key Findings
- Technology had the highest total profit.
- Office Supplies had the second-highest total profit.
- Furniture had the lowest total profit.
- Technology had the highest average profit.
- Profit varies across the three product categories.

## Conclusion
The analysis provides a simple comparison of profitability across product categories using Excel formulas and visualization.
